talk / QQ + 网易云聚合搜索
=========================

用法
----
关闭再打开 Electron（npm start）。搜索默认查两个来源，按钮「全部 / QQ / 网易」筛选。
同一录音在两边出现时合并为一行，点行内来源选择后再播放。切来源本身不会中断当前歌。
收藏、加列表、入队作用于选中的实际版本；播放条、队列和听歌记录显示真实来源。
听歌页可按来源筛选时长、次数、榜单和记录。来源占比按听歌时长计算，不是音源数量。

网易云当前范围
--------------
当前按非 VIP 免费使用推进，会员接入不列近期工作；QQ 已有链路保持不变。
可搜索目录、播放平台接口确实提供的免费标准完整 MP3、获取公开歌词。
不需要本机安装网易云，也不启动原版程序，不读取客户端 Cookie 或转换缓存。
搜索到会员/付费条目不代表可播；标记「需授权」，仍能收藏和加列表，但本期不提供登录。
登录、本人扫码及会员相关能力，等确有需要时再单独推进。
不做平台间静默替换，不把试听当整首，不把 QQ 权限当作网易权限。

为什么有些同名歌仍分开
----------------------
只有歌名、完整歌手集合、专辑相符且时长相差不超过 2 秒，才合并展示为一组。
现场、翻唱、混音、重制等版本保持分开；缺少专辑信息时也不盲合并。
宁可多显示一行，不擅自把用户选的录音换成另一版。
分组依据是元数据，不是音频指纹；两个平台的具体歌曲 ID 始终分别保留。
这一规则比 Kimi 初稿更保守；统计来源筛选也用明确的三个按钮，而不是隐藏的循环开关。

保护 QQ 与旧数据
---------------
QQ SDK、授权文件目录和原音源校验没有替换，网易用独立请求锁、缓存和错误状态。
一方搜索失败仍显示另一方，可单独重试。重新授权 QQ 不会清掉网易正在使用的音源。
旧版正在运行的窗口不会被强制关闭；它仍使用旧数据库和旧后端。

首次打开新后端才会升级曲目键：qq:<MID> / netease:<ID>。旧 QQ MID 仍可作为输入别名。
升级前自动在 data_dir/backups 保存一致的旧 SQLite 快照，随后一起更新收藏、列表顺序、
队列、当前歌曲、听歌记录与歌词/分析缓存；事务失败全部回滚，不合并冲突或删旧记录。
这不是云同步，也不写两个平台的远端歌单或收藏。
恢复备份前必须关闭所有使用该库的进程，并保留当前库和 WAL/SHM 文件；不能在线覆盖。

验证说明
--------
2026-10-12：148 项 Python 与 42 项 Node 测试通过，另实测 Electron 后台启动、主动关闭
及宿主管道断开后的退出。QQ《晴天》与网易《Carefree》静音播放、暂停、继续通过。
聚合搜索、行内来源键盘操作、混合列表/队列及重启保留、单来源故障/重试均已联调。
PC 1380×900 与窄屏 390×844 已截图检查；模拟故障与真实音源证据分别标记保存。

离线测试涵盖两个来源的严格身份、兼容别名、旧库备份/升级/失败回滚、引用及统计保留，
独立锁/分页/部分失败、播放和歌词路由、QQ 授权对网易音源的隔离，以及前端保守分组。
真实联调只在独立 QA 数据副本及复制的本机 DPAPI 授权中运行；不向主播放器写测试记录。
本机 UI 实测和限制记录在忽略 Git 的 output/playwright/ 下；不会公开账号或签名媒体 URL。
免费曲目验证包含完整响应、MP3 全帧和完整非静音解码，以及静音浏览器播放/暂停/继续。
静音时钟推进不代表扬声器可闻，也不替代本人从头到尾听完的确认。
静音验证不计入有效听歌时长；网易正时长的来源归属与汇总使用明确的离线 fixture 验证。

网易分析也已实跑统一链路：免费《Carefree》的 30–60 秒片段使用本机 Basic Pitch，
得到 311 个音符候选及音域、估计速度等指标。使用全新独立测试库，仅注册网易来源，
不读取 QQ 授权、不启动播放、不写主库或听歌时长；结果在 output/netease-analysis-live.json。
QQ 与网易共用模型、指标与页面，差异在平台音源权限及录音版本/音质，不需另写算法。
当前分析只取 30 秒片段，结果是候选与估计，不是整首精确五线谱或声部分离。

源码与设备
----------
代码只使用配置中的数据/运行目录，无个人盘符/用户名或本机网易安装路径。
本次没有新增依赖：使用 requirements/qq-windows-py312.lock 现有 cryptography/miniaudio。
正常协议参考固定 MIT 上游，保留 notices/netease-api-enhanced-MIT.txt；不安装其 HTTP 服务
或 unblock/替代音源依赖，不分发官方 DLL、界面包、账号资料、音乐或歌词。
