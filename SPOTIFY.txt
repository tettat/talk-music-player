一、官方接口与账号
Web API 与 Web Playback SDK 是不同能力，不能把搜索结果或试听地址当作完整音源。
官方 SDK 的音乐播放要求用户具有 Premium。当前 Development Mode 还要求应用所有者具有 Premium，最多 5 个授权用户，用户须加入白名单。
证据：
https://developer.spotify.com/documentation/web-playback-sdk/reference
https://developer.spotify.com/documentation/web-api/concepts/quota-modes

若后续验证官方路线，桌面授权应走系统浏览器＋PKCE，而不是读取官方客户端密码或秘密。回调需按当时官方 Redirect URI 规则配置。
开发者控制台：https://developer.spotify.com/dashboard
https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow
https://developer.spotify.com/documentation/web-api/concepts/redirect_uri
目前没有为用户创建开发者应用或获取 client ID；也未确认用户是否有 Spotify Premium。不要先要求用户付费。
