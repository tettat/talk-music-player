小黄花 · 谱室 — 可选本机能力

使用
  左侧「谱室」启用；模型未就绪时「选择能力包」。
  歌曲的识谱按钮、更多菜单、当前歌曲播放条均可发起。
  30 秒 / 90 秒 / 整首；片段可指定起点，整首从 0 开始，最多 15 分钟。
  提交即后台入队，不必停留在谱室。阶段及多窗口计数来自实际 worker，不显示伪百分比。
  完成后打开乐谱，可对比原曲 / 钢琴、分别听人声旋律 / 器乐旋律 / 和弦。
  能力和歌曲受模型及对应音源授权限制，不会替换音源、绕过会员/DRM。

本机与安装
  主安装器只带播放器、后端、能力代码；不含账号、音频缓存、个人乐谱或大模型。
  能力包（Python / 推理依赖 / 固定模型权重 / 渲染音色）独立存放。
  在客户端原生目录选择器中选择包含 score-pack.json 的解压目录，校验通过后启用。
  不必安装系统 Python 或运行 QQ / 网易官方客户端；账号在新安装的数据根重新连接。
  能力包不在启动时加载。普通听歌不导入 torch，不初始化模型，不占用推理进程。
  主安装数据根可配置；开发环境默认 .private，安装默认个人应用数据目录。
  能力自己的数据固定在 <数据根>/extensions/score-lab/data，不写安装 resources。
  本机模型路径只保存在 bundle-config.json；源码与安装器无个人绝对路径。
  已有独立谱室的 config.json 仍可用 USIC_SCORE_LAB_CONFIG 指定。
  集成能力与独立 demo 使用不同任务目录，不争用旧 demo 的锁或修改旧结果。

任务与退出
  单工作进程 + 最多三个等待项；忙时明确拒绝新任务。
  可取消 / 重试。提交成功后关闭页面不取消；应用退出或停用模块会停止自有模型进程树。
  被中断任务下次可重试，完成结果及已提交输入保留在本机。
  不承诺跨应用退出后继续执行；无常驻服务、无开机自启。
  任务数据按本机用户隔离；不同来源 qq / netease / local 随结果记录。

边界
  Host: web/score-extension.mjs 只接收歌曲 key 和任务公开字段，不接触登录令牌/路径。
  Bridge: src/score_extension.py 单独管理数据、队列、取消、模型入口。
  Capability: capabilities/score_lab 可独立运行，不导入播放器/音乐服务代码。
  Host 仅在准备音频时调用已授权 source，不调用 play，不修改播放列表或听歌统计。
  音频复制到任务自有目录后释放 provider 锁，推理不占用播放的网络锁。
  所有页面、API、媒体和导出使用同一随机 loopback 端口；没有暴露第二个服务。
  唯一可嵌入页面仍限定 frame-ancestors self，其他播放器页面继续禁止被嵌入。
  所有变更要求原 Host/Origin 与主进程下发的 CSRF；无跨域放行，无远端音频上传。
  原生能力包接口只有「用户选择目录并校验」这一操作，不接受 renderer 的文件路径。
  abcjs 点击与选择接口参照 https://docs.abcjs.net/visual/click-listener
  与 https://docs.abcjs.net/visual/dragging.html；编辑的是ABC副本，不是仅移动SVG。
  模型进程由 Windows Job（其他平台进程组）管理；没有按进程名批量杀进程。
  编辑另存修订，原始识别结果不覆盖；编辑支持范围见 EDITING.txt。
  和弦低音谱来自已识别和弦的 MIDI 配器，不等于逐乐器恢复原伴奏。

扩展方式
  capability.json 描述本能力边界。未来学习能力可新增独立能力目录 / UI / host grant。
  当前没有加载任意第三方插件或通用执行权限，也没有建立复杂插件平台。
